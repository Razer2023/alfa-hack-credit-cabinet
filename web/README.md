# Веб-интерфейс (область D)

React 18 + TypeScript + Vite на дизайн-системе Альфа-Банка `@alfalab/core-components@50.37.0`, тема `corp`. Правила оформления — в [docs/design/DESIGN.md](../docs/design/DESIGN.md).

## Разработка
Нужен Node.js 22 (не ниже 20.19).

```bash
cd web
npm ci
npm run dev        # http://localhost:5173, /api проксируется на ядро http://localhost:8000
npm run lint
npm run build
```

Ядро на другом адресе: `CORE_URL=http://localhost:8080 npm run dev`.

## Экраны
Интерфейс выбирает роль вошедшего пользователя.

| Роль | Адрес | Экран |
|---|---|---|
| — | `#/` | Вход, список демо-пользователей |
| Клиент | `#/` | Каталог продуктов (S1.1) и мои заявки |
| Клиент | `#/applications/:id` | Мастер заявки: ИНН → условия с расчётом платежа → отправка кодом (S3.1–S3.4); «нужны данные»; решение, контрпредложение, подписание (S6.1, S6.2, S7.1); трекер и история (S4.5) |
| Банк | `#/` | Очередь заявок с фильтрами (S4.3) |
| Банк | `#/bank/:id` | Карточка андеррайтера: анкета, проверки, скоринг, история; решение и запрос данных (S5.3, S5.4, S4.4) |

- Кнопки показываются строго по `allowed_actions` из ответа ядра, статусы и подсказки берутся из `status.title` / `status.hint`.
- Живые обновления: одно SSE-соединение на приложение (`src/events.ts`), экраны подписываются через `useApplicationEvents`.
- Роутинг на `#`, без отдельной библиотеки (`src/router.ts`).

## Типы API
Типы генерируются из контракта ядра, руками их не пишем:

```bash
npm run gen:api    # contracts/core.yaml → src/api/schema.d.ts
```

Удобные имена — в `src/api/types.ts`. CI (`web-build`) падает, если `schema.d.ts` не совпадает с контрактом.

## Docker
Образ собирает статику и раздаёт её через nginx (порт 80). Запросы `/api/` nginx проксирует на `core:8000`, поток событий `/api/v1/stream` — без буферизации ([nginx.conf](nginx.conf)).

## Тема и стили
- `src/index.css` подключает токены `vars/bundle/corp.css` и тему компонентов `themes/corp.css`.
- Цвета и отступы — только токены: `--color-light-*`, `--gap-<px>` (`--gap-16`, `--gap-24` …). Именованные `--gap-m`, `--gap-l` и часть цветов в библиотеке помечены устаревшими, их не используем.
- Миксины типографики (`@mixin headline_small` и т. п.) обрабатывает `postcss-mixins`, чтобы использовать их в CSS-модуле, импортируйте `@alfalab/core-components/vars/typography.css` в начале файла.
- Шрифт системный: фирменные шрифты банка не подключаются.
