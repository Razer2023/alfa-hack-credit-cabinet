# Правила для ИИ-ассистентов (Claude Code и др.)

Проект — прототип «Умного кредитного кабинета» для Альфа Хак 2026. Командные правила — в [CONTRIBUTING.md](CONTRIBUTING.md), они обязательны и для ассистента. Ниже — то, что ассистенту особенно важно не нарушить.

## Чья ты область
- Ты работаешь от имени конкретного разработчика и **только в его области** из [docs/team/AREAS.md](docs/team/AREAS.md). Если область неизвестна, спроси, прежде чем менять код.
- Для лида (область A) это `services/core/`, `contracts/core.yaml`, `deploy/`, docker-compose, `.github/`, `docs/`.
- Нужны изменения в чужой области — не правь её, а создай ТЗ по шаблону `tz/_TEMPLATE.md` в папке этой области.

## Git
- Синхронизация — только `git pull`, перед началом работы и перед `git push`.
- Никогда: `push --force`, rebase запушенных веток, удаление или пересоздание удалённых веток, `reset --hard` на общих ветках, коммиты напрямую в `main`.
- Работа — в ветке `feat/…`, `fix/…`, `docs/…`, `tz/…` и через Pull Request на GitHub.
- Коммиты — по-русски, «Область: что сделано», со story ID, от имени разработчика из локального `git config`.
- Не сливай PR, не создавай и не пушь теги `v*`, не запускай деплой и не меняй настройки репозитория без отдельного явного «да» от лида в чате. Одобрение одного действия не распространяется на следующие.

## Дизайн
- Интерфейс строится только на дизайн-системе Альфа-Банка `@alfalab/core-components` (React), тема `corp`. Правила и соответствие компонентов историям — в [docs/design/DESIGN.md](docs/design/DESIGN.md).
- Сначала готовый компонент, потом свой из примитивов библиотеки. Цвета, отступы и типографика — только токены. Сторонние UI-киты (shadcn, MUI, Ant) не подключать.
- Пропсы компонентов сверять с документацией https://core-ds.github.io/core-components/master/, а не по памяти.

## Ограничения кейса
- Всё запускается через `docker compose up` без внешних платных сервисов и без доступа к системам банка.
- LLM — только модели с открытыми весами, локально. Основной сценарий обязан работать без ИИ.
- Только синтетические данные. Секреты — только dev-значения в `.env.example`, в чат их не выводить.
- Весь пользовательский сценарий — внутри веб-интерфейса (никаких email, SMS, мессенджеров).
