# Каркас web/ на дизайн-системе Альфа-Банка

## Зачем
Решили делать интерфейс в стиле Альфа-Банка на их открытой дизайн-системе Core Components (MIT). Так прототип выглядит как настоящий продукт банка, а на защите это сильный плюс. Все правила — в [docs/design/DESIGN.md](../../docs/design/DESIGN.md).

## Что нужно сделать
- Каркас `web/`: React + TypeScript, сборщик на твой выбор (Vite предпочтительнее).
- Подключить `@alfalab/core-components@50.37.0` с точной версией и lock-файлом, тема `vars/bundle/corp.css`.
- Настроить PostCSS для миксинов типографики (`postcss-import`, `postcss-mixins`), если понадобятся.
- Базовый макет: шапка, навигация «Клиент / Банк», подвал с пометкой «Прототип. Данные синтетические».
- Dockerfile для `web/`: сборка + nginx, сервис `web`, порт 80 внутри. Подробности про прокси к ядру — в [2026-10-21-a-core-api.md](2026-10-21-a-core-api.md). В `docker-compose.yml` его добавлю я.
