# ТЗ между областями

Если тебе нужна работа в чужой области, не правь её код. Создай здесь файл по шаблону [_TEMPLATE.md](_TEMPLATE.md) в папке нужной области:

| Папка | Владелец |
|---|---|
| `A-core/` | лид: ядро, контракт `core.yaml`, docker, CI, документация |
| `B-integrations/` | данные, моки, документы |
| `C-scoring/` | продукты, скоринг, решение |
| `D-web/` | интерфейс |

Имя файла: `<ГГГГ-ММ-ДД>-<от-кого>-<кратко>.md`, например `2026-10-22-d-nextaction-field.md`.
Порядок работы с ТЗ — в [CONTRIBUTING.md, раздел 5](../CONTRIBUTING.md#5-тз-для-другой-области).
