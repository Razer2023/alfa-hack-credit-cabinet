# Дизайн: дизайн-система Альфа-Банка (Core Components)

Весь интерфейс (область D) строим на открытой дизайн-системе Альфа-Банка **Core Components**, а не на сторонних UI-китах.

- Документация и витрина компонентов: https://core-ds.github.io/core-components/master/?path=/docs/intro--docs
- Исходники: https://github.com/core-ds/core-components, лицензия **MIT**, подходит под ограничения кейса.
- Версия на момент выбора: **50.37.0**. Фиксируем точную версию в `package.json` и в lock-файле.

## Подключение

Библиотека написана на React, поэтому фронтенд — **React + TypeScript**.

```bash
yarn add @alfalab/core-components@50.37.0
```
```tsx
import { Button } from '@alfalab/core-components/button';
```

Тема и CSS-переменные подключаются один раз в корневом файле (`app.css`, `App.tsx`):
```css
@import '@alfalab/core-components/vars/bundle/corp.css';
```

- **Тема — `corp`.** Это продукт для бизнеса (кабинет предпринимателя и рабочее место банка). Если с бандлом `corp` что-то не заработает, берём `@alfalab/core-components/vars/index.css` и тему по разделу «Темизация» в документации.
- На странице одна тема и одна палитра (по умолчанию bluetint). Тёмный режим не делаем.
- Если какая-то зависимость тоже тянет core-components, выравниваем версии через `"resolutions"` в `package.json`.

## Шрифты

Используем **системный шрифтовой стек по умолчанию** (`--font-family-system`, он уже задан в компонентах).
Фирменные шрифты Styrene UI и Alfa Interface Sans **не подключаем**: они раздаются с CDN банка, а решение должно работать автономно и без закрытых лицензий (ограничения кейса). Лицензия на эти шрифты в открытом доступе не указана.

## Правила для интерфейса

1. **Сначала ищем готовый компонент** в Core Components, свой пишем только если подходящего нет. Свой компонент собираем из примитивов библиотеки (`Typography`, `Gap`, `Space`, `Stack`, `Grid`) и CSS-переменных (цвета, отступы), без произвольных hex-цветов и px-отступов.
2. **Текст — через `Typography.Title`, `Typography.TitleResponsive`, `Typography.Text`.** Миксины из `vars/typography.css` — только когда компонент не подходит. Для миксинов нужен PostCSS (postcss-mixins, postcss-import): это настраивается при сборке `web/`.
3. **Цвета, отступы, брейкпоинты — только токены** из разделов Tokens & assets документации.
4. **Доступность:** соблюдаем раздел Accessibility (формы, клавиатура, подписи полей) — это часть критерия «качество UX».
5. **Устаревшие компоненты** (раздел *Deprecated components* в документации) не используем.
6. Это прототип для хакатона: в интерфейсе не используем логотипы и названия реальных продуктов банка как будто это боевой сервис. В подвале — пометка «Прототип. Данные синтетические».
